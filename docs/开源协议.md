1. **非官方**：本项目与暴雪娱乐无任何隶属、赞助或背书关系，未获授权也未主张授权。
2. **非商业**：严禁任何形式的收费、销售、付费分发与变相牟利；免费分享必须保留全部声明。
3. **分层授权**：`LICENSE` 只授权作者自研的代码、脚本、文档与自绘界面/合成音效；
   卡牌名称、卡牌数据、原版插画、商标等第三方内容不在授权范围内（`LICENSE` 第 3 节）。
4. **来源如实标注**：所有第三方素材保留原始来源，明文声明权利人不属于本项目。
5. **现状提供**：不附带任何担保，作者不承担使用产生的任何损害赔偿责任。
6. **配合下架**：收到有效权利通知后 72 小时内删除或下架相关内容并停止分发。

## 与程序内协议页的关系

程序首次启动时展示的「开源协议与责任告知」页取自 `src/game/license.ts` 中的
`LICENSE_CLAUSES`，与根目录三份文件是**同一套立场的两个载体**：

- 修改根目录条款正文后，应同步更新 `src/game/license.ts` 中的条款文案；
- 条款有**实质变化**时递增 `LICENSE_VERSION`，玩家会被重新要求确认；
- `scripts/coverage.ts` 会把 `LICENSE_VERSION` 与条款条数写入覆盖报告，
  同步后需要重新生成覆盖报告。
